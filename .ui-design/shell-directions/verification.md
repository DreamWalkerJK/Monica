# Prototype verification

Browser smoke checks were run against the local static preview with Chromium through `playwright-cli`.

- All three directions were checked in light and dark appearance: top navigation at 1440, 1050, 929, 761, 760, and 390 pixels wide, plus sidebar navigation at 1440, 929, and 390 pixels: 54 combinations. Every top header measured 56px with brand and tools contained in the same row. The matrix had no JavaScript page errors, failed asset responses, external requests, horizontal document overflow, or unloaded declared fonts. The workspace owned content scrolling.
- Each direction was exercised through category browsing without route changes, group disclosure, nested leaf selection, collapse to a measured 64-pixel rail, temporary context flyouts, and selection while remaining collapsed.
- Top navigation was checked for nested destinations, repeated ArrowDown opening without toggling closed, Escape dismissal, and focus restoration. Its More menu retained nested groups and the current category marker. Resizing an open category into More and expanding an open More menu back to full navigation closed stale panels and restored visible focus. Crossing 760/761px closed the mobile drawer and transferred navigation focus between the drawer trigger and desktop navigation.
- Appearance settings were checked for Cancel, Apply, layout and color persistence after reload, module filter preservation, and focus restoration. Layout and theme query parameters were cleared on Apply so saved preferences governed subsequent reloads.
- Workspace search resolved nested destinations in all directions. Mobile selection closed the combined drawer; Escape returned focus, the background became inert, and Tab wrapped inside the drawer. Settings opened from that drawer remained usable at 390 × 640 pixels.
- The gallery was checked at 1440, 929, and 390 pixels across its six review layout/appearance combinations: 18 combinations. All preview images loaded without horizontal overflow. Embedded direction switching, Appearance settings, hierarchical top menus, and returning to the gallery were checked.
- Earlier content checks covered module filtering and empty results, module detail dialogs, search, and Lumen's local preference form. The navigation refinement did not change the underlying sample page actions.
- The layout matrix used reduced motion. Screenshots in `screenshots/` record desktop and mobile alternatives, collapsed/flyout navigation, grouped top menus, Appearance settings, and the refreshed comparison gallery.

Review corrections included variant palette precedence, the single-row header composition, mobile breadcrumb containment, and restoring focus after navigating, closing a flyout, or moving between desktop and mobile navigation. Appearance’s top-layout miniature now depicts one navigation band.

These checks cover standalone design prototypes with sample data. No production framework code, generated skills, or public contracts changed. The .NET build/test gate was not run for this prototype-only change. Implementation fidelity, registry-driven overflow, localization, authorization, and real host behavior remain part of the later implementation after a direction is selected.
