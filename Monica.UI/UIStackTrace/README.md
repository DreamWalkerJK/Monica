# UIStackTrace

The shared `StackTraceViewer` reads complete captured diagnostic text with conservative inline highlighting, local wrapping and exact-payload Copy.

Consumer registration, prerequisites, source fidelity, clipboard/lifetime behavior and embedded caller guidance are owned by [Embedded diagnostic text](../../skills/monica-infra-ui/references/stack-trace.md).

Component authoring and visual verification use [Monica UI development](../../skills/monica-ui-development/SKILL.md) and [Monica UI audit](../../skills/monica-ui-audit/SKILL.md). The implementation lives in `Components/` and `Support/`.
